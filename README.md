# final_project_QA

📌 Описание проекта:

Финальный проект по QA, включающий практическое тестирование веб-приложения, создание базы данных, работу с API, Bash‑скрипты и другие материалы, использованные в рамках курса.

Проект демонстрирует полный цикл тестирования: от составления тест-кейсов до документации багов и автоматизации процессов.

🗂 Структура проекта:

├── .github/workflows       — CI/CD workflow

├── Bash_script             — Bash-скрипты

├── Charles                 — Инструменты: rewrite, map local, breakpoint

├── Client_server           — Клиент-серверная архитектура, диаграмма

├── Postman                 — Коллекции Postman для API-тестов

├── SQL                     — SQL-запросы и схемы БД

├── bash_commands           — Команды bash для практики

├── bug_reports             — Баг-репорты

├── test_cases              — Тест-кейсы



🧪 Выполненные задачи по направлениям:

1️⃣ Веб-приложение Bank Saint-Petersburg

Созданы 3 баг-репорта в JIRA.

Покрыто  3 тест-кейсами. 

Результат: тест-кейсы и баг-репорты хранятся в папках test_cases и bug_reports.



2️⃣ База данных

Создана база данных для банка с таблицами

Login_password — логины и пароли пользователей

Users — конкретные пользователи

Bank_cards — банковские карточки пользователей

Users_messages — сообщения пользователей

Проработаны отношения между таблицами

Файлы SQL хранятся в папке SQL



3️⃣ Postman / API

Создана новая коллекция в Postman

Реализованы основные запросы: GET, POST, PUT, DELETE

Минимальное покрытие тестами: до 3-ех теста на каждый запрос

Коллекция может запускаться из командной строки

Коллекция хранится в папке Postman



4️⃣ Charles Proxy

Практическая работа с сетевым трафиком:

Подмена статус-кода через Rewrite

Подмена тела ответа через Map local

Удаление или изменение заголовков через Breakpoint

Настройки и файлы хранятся в папке Charles



5️⃣ Bash

Создан Bash-скрипт для автоматизации задач

Команды и скрипты находятся в папках Bash_script и bash_commands



6️⃣ Клиент-серверная архитектура

Построена схема взаимодействия клиент-сервер

Использован Flowchart Maker & Online Diagram Software

Диаграммы хранятся в папке Client_server



📌 Результат

Проект демонстрирует:

Практическое тестирование веб-приложений

Создание и проектирование БД

Работа с API и автоматизация тестирования

Анализ сетевого трафика

Построение схем клиент-серверного взаимодействия
